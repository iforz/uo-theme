把博客主题做成跨引擎的

uo约 3 分钟 · 900 字

目录

    同一套设计，在 WordPress、Typecho、Hexo 上都能用——前提是把呈现和数据分开。

    标记约定

    所有样式只依赖 uo-* class，所有交互只依赖 data-uo-* 属性。

    模板语言可以不同，输出的 HTML 结构保持一致即可。

    正文区域

    正文放在 .uo-prose[data-uo-content] 中，目录、代码复制和图片放大会自动启用。

    <div class="uo-prose" data-uo-content>…</div>

    适配器

    管理面板只调用 window.UOAdapter，实现它就能获得写作、审核、媒体和外观设置界面。

    • WordPress：核心 REST + nonce
    • 静态站点：localStorage 或 Git API

    主题变量

    只有 CSS 变量是公开接口，深色模式由 data-uo-scheme 控制。
