# 0.1.0 验证记录

日期：2026-11-12。交付层级：主题起始模板，待用户审核。

## 已验证

- 本机 PHP 8.5.5：所有主题与工具 PHP 文件语法通过。
- 主配置与深色变体 JSON 可解析，声明 theme.json v3。
- 14 个模板、模板部件和 PHP 区块样板：区块 JSON、成对嵌套、本地引用通过。
- 使用 WordPress 官方 `6.6` 标签的 `WP_Block_Parser` 解析全部 14 个文件通过；源码来自 WordPress/WordPress GitHub 仓库，仅作为外部验证输入，不打包。
- 安装包使用运行文件白名单，顶层为 `uo-theme/`，排除 Git、开发脚本、文档与凭据；附 SHA-256。
- 仓库提供 GitHub Actions 静态检查配置；远端 CI 是否运行通过以 Actions 实际结果为准。

## 未验证与限制

- 未安装数据库驱动的完整 WordPress 站点；完整测试包下载缓慢，已停止。
- 未完成 theme.json 官方 JSON Schema 校验（本地缺依赖，下载超时）；现有检查仅验证 JSON 与版本声明。
- 未完成浏览器视觉、后台启用/保存、移动端菜单、分页/搜索、评论与插件兼容验收。
- 最低 PHP 7.4 是语法与 API 目标，尚未在 PHP 7.4 运行；不可将当前结果当作最低版本实测。
- 用户未确认视觉风格；没有主题预览截图、独立插件、生产部署或 WordPress.org 上架。

## 安装后验收清单

1. 上传并启用 ZIP，确认没有 PHP 错误。
2. 站点编辑器修改导航、Logo、颜色与模板后保存，刷新检查。
3. 切换浅色/Forest night；桌面和手机检查导航及文章网格。
4. 创建足够文章验证分页；检查搜索有/无结果、归档、404、文章评论与前后导航。
5. 静态首页与文章首页分别验证；再检查实际所需插件。
